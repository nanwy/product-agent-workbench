# 0003 通过工作台托管预览完成页面验收

**Type:** AFK
**Status:** Done

## What to build

把页面运行和访问职责收敛到工作台已有的目标项目进程与 localhost 预览网关。候选实现形成后，工作台启动或复用显式配置的开发服务，等待健康检查，再把目标路由加载到预览区域；执行 Agent 不应自行启动监听端口、curl 本地服务或通过 Computer Use 打开外部域名。

这条完整路径需要处理端口已被旧进程占用、工作台拥有的子进程提前退出、健康地址由其他进程响应以及预览网关无法连接上游等情况。工作台只能终止自己创建的进程，不得清理或杀死用户已有开发服务。

该切片完成后，Codex 沙箱中的 `listen EPERM`、无法访问 `127.0.0.1:3003`，以及浏览器拒绝访问 `ctf.chuzelab.com` 都不再阻断普通本地页面的产品验收。

## Acceptance criteria

- [x] 执行票完成后，工作台可以启动或复用配置的目标项目运行时并等待健康检查。
- [x] 目标路由通过 localhost 预览网关显示，产品可以刷新并外部打开。
- [x] 执行 prompt 不再要求 Agent 在受限沙箱中启动服务或操作浏览器完成页面验收。
- [x] 端口冲突能区分“工作台拥有的进程失败”和“已有进程可安全复用”。
- [x] 停止操作只终止工作台拥有的进程组，用户已有进程保持运行。
- [x] 自动化测试覆盖就绪、启动失败、陈旧健康响应、端口占用和上游不可达。
