第一张表速查卡

从领域字段到数据库约束。用于复习和打印，不代替亲手完成练习。

字段回答“保存什么”；约束回答“什么绝不能被保存”。

通用形状

CREATE TABLE 表名 (
    字段名 类型 列约束,
    字段名 类型 列约束,
    CHECK (表级条件)
);

同构示例：文章表

CREATE TABLE articles (
    id TEXT NOT NULL PRIMARY KEY,
    author_id TEXT NOT NULL,
    title TEXT NOT NULL,
    status TEXT NOT NULL,
    version INTEGER NOT NULL,
    CHECK (version >= 1),
    CHECK (status IN ('draft', 'review', 'published'))
);

Requirement 映射

领域字段SQLite 类型必须保护的不变量
IDTEXT非空、唯一身份
ProjectIDTEXT不能为空
TitleTEXT不能为空
StageTEXT非空、只能取六个领域值
RevisionINTEGER非空、至少为 1

约束与错误

PRIMARY KEY

拒绝第二条记录冒用同一个 Requirement ID。

NOT NULL

拒绝缺失项目、标题、阶段或版本的残缺事实。

CHECK

拒绝 revision=0，以及拼错或越界的 stage。

提交前四问

  1. 每个字段有明确类型吗？

    本课只需要 TEXT 和 INTEGER。

  2. 必填字段都显式 NOT NULL 吗？

    不要依赖调用方永远正确。

  3. 非法枚举和数值会被 CHECK 拒绝吗？

    用一条错误 INSERT 反向验证。

  4. 每条约束都能解释防了什么错误吗？

    解释不出来的约束先不要添加。
